# Acceptable Use Policy (v0.1)

1. Authorized targets only: your assigned session targets. No testing of external systems.
2. No real-world attacks, no credential stuffing, no phishing, no malware upload.
3. No resource abuse, crypto-mining, or egress attempts.
4. No flag sharing, write-up posting during assessments, or automation that degrades shared infra.
5. Content is for education; vulnerabilities are synthetic or pinned historical CVEs in isolation.
6. Violations → session revoke, account suspension, org report.

Learners accept this at signup + at each session launch. All launches audited.
